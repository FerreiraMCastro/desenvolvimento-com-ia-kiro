Portfólio de projetos do curso Desenvolvimento com IA na prática, usando o Kiro da AWS.

| Nº | Projeto | Descrição |
| --- | --- | --- |
| 01 | [Habit Tracker](01-habit-tracker/) | App web para registrar hábitos e acompanhar as conclusões dos últimos sete dias. |

## 01 · Habit Tracker

- Cadastro, edição e exclusão de hábitos.
- Marcação de conclusões por dia, contagem de dias consecutivos e barra de progresso diário.
- Armazenamento no navegador com `localStorage` e importação e exportação em CSV.

O app usa HTML, CSS e JavaScript. Para rodar, baixe o repositório e abra o arquivo `01-habit-tracker/index.html` no navegador.
